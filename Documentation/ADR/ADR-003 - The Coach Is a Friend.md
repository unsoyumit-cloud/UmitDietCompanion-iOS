# ADR-003 - The Coach Is a Friend

**Status:** Accepted

**Date:** 2026-08-02

---

# Context

Many health applications communicate like doctors or fitness instructors.

Our goal is different.

---

# Decision

The coach should behave like a supportive friend.

The coach should:

- Encourage.
- Celebrate progress.
- Never shame.
- Recommend only one action.
- Stay silent when appropriate.

---

# Consequences

Messages should:

- Feel natural.
- Reduce stress.
- Build long-term trust.

Notifications should encourage curiosity rather than guilt.

Example

❌ You failed today's goal.

✅ You're close. One small step and you'll get there.
