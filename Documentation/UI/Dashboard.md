## Health Data Freshness Indicator

The dashboard displays the timestamp of the latest successfully imported
health data.

Purpose:
- Increase user trust.
- Explain potential differences between Garmin Connect and Apple Health.
- Help users understand how current their health metrics are.
- Provide context for AI recommendations.

UI Guidelines:
- Displayed as "Last Update".
- Small caption font.
- Subtle secondary color.
- Positioned at the bottom of the Health Score card.
- Should never compete visually with the Health Score.
- Only visible to users who intentionally look for it.

Future Behaviour:
- Today → Last Update 15:26
- Yesterday → Last Update Yesterday
- Older → Last Update 2 days ago
