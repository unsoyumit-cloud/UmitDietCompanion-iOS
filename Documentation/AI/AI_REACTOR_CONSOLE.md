# ☢️ AI Reactor Console

## Purpose

AI Reactor Console is the internal developer console of Ümit Diet Companion.

It allows developers to observe the complete AI decision pipeline in real time.

This screen is **not** a debugging screen.

It is an inspection tool for understanding how the AI reaches a coaching decision.

---

# Core Principle

The Reactor Console NEVER changes AI behaviour.

It only observes it.

Every value displayed on the screen must come directly from the existing AI pipeline.

No additional business logic should ever be implemented inside the Reactor Console.

---

# Pipeline

The console visualizes every stage of the AI pipeline.

```
DailyHealthSnapshot
        │
        ▼
HealthContextBuilder
        │
        ▼
AIContext
        │
        ▼
ObservationEngine
        │
        ▼
InsightEngine
        │
        ▼
RecommendationEngine
        │
        ▼
ReasoningEngine
        │
        ▼
CoachMessageFactory
```

Every stage should be individually inspectable.

---

# Module Status

Each module has one execution state.

🟢 Success

The module executed successfully and produced valid output.

---

🟡 Warning

The module executed successfully but requires attention.

Examples

- Empty observations
- Default values used
- Optional service unavailable
- Confidence below expected threshold

---

🔴 Failure

The module failed.

Examples

- Exception
- Invalid output
- Required data missing

---

⚪ Not Executed

Pipeline has not reached this stage.

---

# Screen Sections

The console is divided into logical inspection sections.

1. Snapshot
2. Context
3. Observation
4. Insight
5. Recommendation
6. Reasoning
7. Coach Message

Each section can be expanded independently.

---

# Snapshot

Displays the raw data entering the AI.

Examples

- Weight
- Water
- Calories
- Steps
- Sleep
- Heart Rate
- Health Score

---

# Context

Displays every generated context object.

Examples

- HealthContext
- UserContext
- EnvironmentContext
- RecommendationContext

---

# Observation

Displays every generated observation.

Example

- hydrationLow
- movementLow
- busyMeetingDay

---

# Insight

Displays generated insights.

Example

- hydrationOpportunity
- healthyMealOpportunity
- movementOpportunity

---

# Recommendation

Displays recommendations generated by RecommendationEngine.

Example

Recommendation Type

Priority

Confidence

Supporting Insights

---

# Reasoning

Displays WHY the AI selected the final recommendation.

This is one of the most important sections of the Reactor Console.

---

# Coach Message

Displays the final message shown to the user.

No formatting differences should exist between the console and the production application.

# Design Philosophy

The Reactor Console is inspired by a reactor control room.

Every module behaves like an independent subsystem.

Developers should immediately understand

- where the pipeline is,
- what succeeded,
- what failed,
- and why.

The console should make AI behaviour transparent.
