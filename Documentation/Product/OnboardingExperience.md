# Onboarding Experience

## Goal

The onboarding experience should help users feel welcomed, understood, and excited to begin their health journey.

The goal is not to collect data.

The goal is to start building trust.

The onboarding should take less than one minute.

---

# Core Principles

- Ask only what is necessary.
- Never overwhelm the user.
- Explain why a question is being asked.
- Allow personalisation to happen over time.
- Every question should improve future coaching.

---

# User Journey

## Step 1 — Welcome

Purpose

Create a friendly first impression.

Message

"Welcome to Ümit Diet Companion."

"Let's spend about 30 seconds getting to know each other."

The user should immediately understand that this application is different from a traditional health tracker.

---

## Step 2 — Health Goal

Question

What would you like to achieve?

Options

- Lose weight
- Live healthier
- Stay active
- Simply track my health

Purpose

This becomes the primary coaching objective.

---

## Step 3 — Eating Style

Question

Which eating style best describes you?

Options

- Standard
- Intermittent Fasting
- Vegetarian
- Vegan
- Other

Purpose

Prevent inappropriate coaching.

Example

Do not recommend breakfast to an intermittent fasting user.

---

## Step 4 — Coach Personality

Question

How would you like your coach to communicate?

Options

😊 Friendly

📘 Balanced

🎯 Motivational

Purpose

Allow users to feel ownership of their companion.

Regardless of the selected style, the coach should always remain respectful and supportive.

---

## Dashboard

The dashboard should appear immediately after onboarding.

No additional setup screens.

No permission overload.

The user should begin experiencing value immediately.

---

# Progressive Profiling

The application should continue learning gradually.

Instead of asking many questions on day one, ask one small question occasionally.

Examples

"By the way..."

"Can I ask you something to improve my suggestions?"

Possible questions

- Do you usually eat breakfast?
- Do you smoke?
- Do you drink alcohol?
- How often do you exercise?
- What time do you usually go to bed?
- Would you like more or fewer notifications?

Each question should require only one tap.

---

# What We Will Never Do

- Long questionnaires.
- Mandatory profile completion.
- Medical-style interviews.
- Asking questions without explaining their purpose.
- Blocking access to the dashboard.

---

# Success Criteria

A successful onboarding experience should make users feel:

- Welcome
- Curious
- Understood
- Comfortable

At the end of onboarding, the ideal reaction is:

"I'm curious what this companion will tell me tomorrow."
