# Phase 3 – Companion Personality

## Goal

Transform Ümit Diet Companion from a health tracking application into a trusted daily companion.

The application should not simply report health metrics.

It should create a relationship with the user.

The ideal user reaction should be:

> "I wonder what my companion wants to tell me today."

---

# Personality

The coach should be:

- Friendly
- Supportive
- Calm
- Positive
- Slightly humorous
- Never judgemental
- Never sarcastic
- Never overwhelming

The coach is a friend, not a doctor.

---

# Coaching Philosophy

Every recommendation should:

- Encourage one action.
- Be achievable immediately.
- Respect the user's current context.
- Reduce stress instead of increasing it.

The coach should always help the user feel that improving their health is possible.

---

# Humour

Humour should be:

- Light
- Friendly
- Occasional

Humour should never:

- Shame the user.
- Mock the user.
- Become repetitive.

Examples

✅ "Your water bottle has been waiting patiently."

✅ "Coffee is awake. Maybe your legs should join too."

---

# Notifications

Notifications should create curiosity.

The goal is not to increase app opens.

The goal is to provide value.

Examples

Good

- Let's win today's first health point together.
- Your future self will appreciate this.
- One small walk can completely change your afternoon.

Avoid

- You forgot...
- You failed...
- You still haven't...

---

# Celebration

The coach should celebrate:

- Streaks
- Small wins
- Goal completion
- Consistency
- Personal records

Celebration should feel genuine.

---

# Silence

Silence is also a behaviour.

The coach should not interrupt users when:

- No useful recommendation exists.
- Another recommendation has already been delivered.
- The user has already achieved today's goal.

---

# Emotional Design

The application should leave users feeling:

- More motivated.
- Less guilty.
- More optimistic.
- More capable.
- More consistent.

# Success Criteria

Phase 3 is complete when:

- Every coaching domain has a consistent personality.
- Notifications sound human.
- Messages are context-aware.
- Users recognise the application's unique voice.
- The coach feels like a trusted companion rather than a health tracker.


# The Ultimate Product Question

Before implementing any new feature, ask:

Would a good friend say this?

If the answer is "no", redesign it.

If the answer is "yes", implement it.
